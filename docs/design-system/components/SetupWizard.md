Podłączenie AI (`SetupWizard`): jedno okno, jeden reaktywny ekran. Pytanie o cel ustawia zakres, pod nim drabina kroków do pełnej integracji, odhaczana na żywo. Nie otwiera się samo po logowaniu.

- **Wejścia:** (1) podpowiedź przy funkcji AI bez podłączenia (niżej), (2) Ustawienia > Claude Code, przycisk „Connect AI”, (3) kropka `accent` 6 przy „Settings” w pasku bocznym, dopóki krok 1 nie jest zrobiony (nie w demo). Bez karteczek i okien na start.
- **Okno:** jak `askConfirm`, ale szersze: `bg-popover`, `shadow-popover`, `radius-xl`, szerokość 560 (wyjątek „okna”). Escape, „×” i „Later” zamykają; klik w tło nie zamyka. Na telefonie pełny ekran.
- **Nagłówek:** tytuł `text-xl` 600 „Connect AI to Exponential”, pod nim jedno zdanie `text-secondary`.
- **Pytanie o cel:** etykieta `text-sm` 500 „What do you want AI for?”, trzy wiersze-opcje (radio, `radius-lg`, ramka `border`, wybrany: ramka `accent` 60% i tło `accent` 10%): tytuł `text-md` 500 + jedno zdanie `text-tertiary`. Poziomy: 1 „Ask about and update issues”, 2 „…and have issues record my work”, 3 „…and have AI work while I'm away”. Domyślny: najwyższy zrobiony poziom, a gdy nic nie ma: 2. Wejście z funkcji AI wybiera jej poziom (Analyze, Start work → 3).
- **Drabina:** kroki 1 „Connect a client”, 2 „Turn on work trace”, 3 „Agent on this computer”, połączone pionową kreską `border`. Kółko 22: zrobiony `success` z ✓, bieżący obrys `accent`, przyszły obrys `border`. Kroki powyżej wybranego celu wyszarzone (opacity) z podpowiedzią „Not needed for this goal”, nie ukryte. Rozwinięty jest jeden krok: domyślnie pierwszy niezrobiony w celu, a kliknięcie tytułu innego kroku w celu (też zrobionego, np. żeby dodać drugiego klienta) rozwija ten; zrobione to jeden wiersz ze stanem `success-text` („Claude Code · connected 2 minutes ago”).
- **Krok 1:** zakładki (segment) klient Claude Code / Codex i miejsce VS Code / Cursor / Terminal; pod nimi jedno polecenie (blok `mono` `text-sm`, `bg-secondary`, `radius-md`, przycisk-ikona „Copy”) albo dla Cursora `btn primary` „Open in Cursor” z poleceniem pod „Use a command instead”. Zrobiony, gdy serwer zobaczy pierwsze wywołanie MCP (OAuth `firstMcpAt` albo użyty token).
- **Krok 2 (tylko Claude Code):** polecenie instalacji pluginu. Zrobiony, gdy serwer dostanie pierwszy ślad pracy od użytkownika. Przy Codex wyszarzony z podpowiedzią „Claude Code only”.
- **Krok 3:** `btn primary` „Download exponential-agent.exe”, jedno zdanie `warning-text` o ostrzeżeniu Windows, polecenia `login` i `autostart on`, potem komputery (online `success-text`) i ich repo: klucz projektu · ścieżka `mono` albo „no repo” + `btn sm` „Choose folder”. Zrobiony, gdy jakiś komputer użytkownika jest online i aktualny.
- **Czekanie:** stan kroku to pulsująca kropka `text-tertiary` + „Waiting for the first call…” (puls wyłączony przy `prefers-reduced-motion`). Odświeżanie co 3 s, gdy okno jest otwarte. Po 2 minutach pod spodem `hint` „Not working?” z typowymi przyczynami dla wybranego klienta. Stanu błędu nie ma.
- **Stopka:** pasek postępu (wysokość 4, `accent`) i „1 of 2” `text-sm` `text-tertiary` liczone w obrębie celu; po prawej `btn` „Later” i `btn primary` „Done” (zawsze aktywne). „Done” przy pełnym celu zapisuje na serwerze `setupDoneAt`; kropka w pasku znika po kroku 1.
- **Telefon:** bez poleceń i pobierania. Tylko stan trzech poziomów (wiersze jak wyżej, bez rozwinięć) i zdanie „Connecting is done on a computer, in Settings > Claude Code. From the phone you can request analyses; your computer runs them when it is on.”
- **Podpowiedź przy funkcjach AI:** Analyze / Deep / Start work bez podłączenia nie dają błędu, tylko popover (`bg-popover`, `radius-lg`, szer. do 320) pod przyciskiem: tytuł `text-md` 600 („Analysis is done by AI on your computer”), zdanie skutku, `btn primary sm` „Connect AI” (otwiera okno z celem tej funkcji) i `btn sm` „Not now”.
- **Połączone klienty** (Ustawienia > Claude Code, karta `.s-card` jak `AgentList`): wiersz nazwa klienta · `hint` „since dd.mm.rrrr, last used …” · `btn sm danger` „Revoke” przez `askConfirm`.
- Animacja rozwinięcia kroku 120 ms, wyłączona przy `prefers-reduced-motion`.
