Podłączenie AI (`SetupWizard`): jedno okno, jeden reaktywny ekran. Pytanie o cel ustawia zakres, pod nim drabina kroków do pełnej integracji, odhaczana na żywo. Nie otwiera się samo po logowaniu.

- **Wejścia:** (1) podpowiedź przy funkcji AI bez podłączenia (niżej), (2) Ustawienia > Moje AI, przycisk „Connect AI”, (3) kropka `accent` 6 przy „Settings” w pasku bocznym, dopóki krok 1 nie jest zrobiony (nie w demo). Bez karteczek i okien na start.
- **Okno:** jak `askConfirm`, ale szersze: `bg-popover`, `shadow-popover`, `radius-xl`, szerokość 560 (wyjątek „okna”). Escape, „×” i „Later” zamykają; klik w tło nie zamyka. Na telefonie pełny ekran.
- **Nagłówek:** tytuł `text-xl` 600 „Connect AI to Exponential”, pod nim jedno zdanie `text-secondary`.
- **Pytanie o cel:** etykieta `text-sm` 500 „What do you want AI for?”, trzy wiersze-opcje (checkbox, `radius-lg`, ramka `border`, zaznaczony: ramka `accent` 60% i tło `accent` 10%). Poziomy są narastające: wybór poziomu zaznacza też wszystkie niższe, odznaczenie najwyższego cofa o jeden: tytuł `text-md` 500 + jedno zdanie `text-tertiary`. Poziomy: 1 „Ask about and update issues”, 2 „…and have issues record my work”, 3 „…and have AI work while I'm away”. Domyślny: najwyższy zrobiony poziom, a gdy nic nie ma: 2. Wejście z funkcji AI wybiera jej poziom (Analyze, Start work → 3).
- **Domyślna ścieżka (pod pytaniem o cel):** jeden ramkowany blok (`border-secondary`, `radius-lg`): mały przełącznik `.seg` Claude Code / Codex / Cursor (domyślnie Claude Code); przy Cursor zamiast pobrania `btn primary` „Open in Cursor” (link `cursor://…/mcp/install`, Cursor sam loguje przez OAuth) z „?” i `Tooltip`, a wiersze śladu pracy i agenta są wyszarzone (`opacity` 0.5, `cursor: not-allowed`, „Unavailable”) z `Tooltip` „Cursor supports only step 1…” (poziomy w obrębie celu, nie ukryte); krok 1 jest zrobiony tylko, gdy podłączonym klientem jest Cursor; przy pozostałych pod nim `btn primary` „Download and run” do `/agent/download?engine=<claude|codex>&goal=<1..3>` (plik z adresem, jednorazowym tokenem parowania i celem; instalator sam podłącza klienta i agenta) z ikoną „?” i `Tooltip` o ostrzeżeniu Windows („Windows may warn about an unsigned file: More info, then Run anyway.”). Niżej status na żywo, tylko do odczytu, bez zakładek: po jednym wierszu na poziom do wybranego celu (klient, ślad pracy, agent): kółko z ✓ (`success-text`) albo pulsująca kropka + „Waiting”, etykieta i stan; przy Codex wiersz śladu pracy nie występuje. Zrobiony poziom: klient, gdy serwer zobaczy pierwsze wywołanie MCP; ślad pracy, gdy przyjdzie pierwszy ślad od użytkownika; agent, gdy jakiś komputer jest online i aktualny. Bez zdań objaśniających: wyjaśnienia w `Tooltip`.
- **Ręcznie:** pod blokiem link-przycisk „Other ways to connect” (`aria-expanded`) rozwija dawny ekran kroków: pasek zakładek `.seg` po jednej na krok (zrobiony ✓ `success-text`, niezrobiony numer `text-tertiary`, otwarty `.on`) i bieżący krok jako ramkowany blok (numer w kółku 22 z obrysem `accent`, tytuł, akcja, linia czekania).
- **Krok 1 (ręcznie):** zakładki klient Claude Code / Codex i miejsce VS Code / Cursor / Terminal; pod nimi jedno polecenie (blok `mono` `text-sm`, `bg-secondary`, `radius-md`, przycisk-ikona „Copy”) albo dla Cursora `btn primary` „Open in Cursor” z poleceniem pod „Use a command instead”.
- **Krok 2 (ręcznie, tylko Claude Code):** polecenie instalacji pluginu. Przy Codex wyszarzony z podpowiedzią „Claude Code only”.
- **Krok 3 (ręcznie):** „Download and run” (jak wyżej), link-przycisk „Use the terminal” z poleceniami `login` i `autostart on`; dalej komputery (online `success-text`) i ich repo: klucz projektu · ścieżka `mono` albo „no repo” + `btn sm` „Choose folder”.
- **Czekanie:** stan kroku to pulsująca kropka `text-tertiary` + „Waiting for the first call…” (puls wyłączony przy `prefers-reduced-motion`). Odświeżanie co 3 s, gdy okno jest otwarte. Po 2 minutach obok linii pojawia się ikona „?” z `Tooltip` „Not working?” i typowymi przyczynami dla wybranego klienta. Stanu błędu nie ma.
- **Stopka:** pasek postępu (wysokość 4, `accent`) i „1 of 2” `text-sm` `text-tertiary` liczone w obrębie celu; po prawej `btn` „Later” i `btn primary` „Done” (zawsze aktywne); gdy cel nie jest w pełni zrobiony, przycisk nazywa się „Close”. „Done” przy pełnym celu zapisuje na serwerze `setupDoneAt`; kropka w pasku znika po kroku 1.
- **Telefon:** bez poleceń i pobierania. Tylko stan trzech poziomów (wiersze jak wyżej, bez rozwinięć) i zdanie „Connecting is done on a computer, in Settings > My AI. From the phone you can request analyses; your computer runs them when it is on.”
- **Podpowiedź przy funkcjach AI:** Analyze / Deep / Start work bez podłączenia nie dają błędu, tylko popover (`bg-popover`, `radius-lg`, szer. do 320) pod przyciskiem: tytuł `text-md` 600 („Analysis is done by AI on your computer”; zdanie skutku w `Tooltip` na tytule), `btn primary sm` „Connect AI” (otwiera okno z celem tej funkcji), przy Analyze `btn sm` „Request anyway” (zleca analizę normalnie) i `btn sm` „Not now”. Gdy projekt ma kolejkę zespołu, Analyze zleca od razu, bez popovera.
- **Połączone klienty** (Ustawienia > Moje AI, karta `.s-card` jak `AgentList`): wiersz nazwa klienta · `hint` „since dd.mm.rrrr, last used …” · `btn sm danger` „Revoke” przez `askConfirm`.
- Animacja rozwinięcia kroku 120 ms, wyłączona przy `prefers-reduced-motion`.
